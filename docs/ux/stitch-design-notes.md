# Stitch Design Notes

## UX Direction
- Product should feel like a premium personal operating system, not an admin panel.
- Visual hierarchy is card-first with clear action blocks.
- Typography and spacing prioritize focus and calm execution.

## Core Screen Intent
- `Today`: command center for day execution.
- `Inbox`: triage stream across all incoming sources.
- `Workout active mode`: dark, focused, low-distraction logging.
- `Nutrition`: dashboard-style summary with quick logging actions.

## Interaction Rules
- Every key card has clear primary action.
- System states must be explicit: loading, success, error, empty.
- Avoid invisible background actions without user feedback.

## Anti-patterns
- Generic CRUD/admin tables.
- Flat utility UI without hierarchy.
- Visual style drift from Stitch-inspired product language.
